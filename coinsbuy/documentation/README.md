# Coinsbuy API Documentation

This folder contains reference documentation for the Coinsbuy API v3 integration.

## Files

- **[API Overview.md](./API%20Overview.md)** - General API information, base URLs, and important announcements
- **[Authentication.md](./Authentication.md)** - OAuth 2.0 authentication process and token obtaining
- **[Wallets.md](./Wallets.md)** - Wallet object structure and wallet management methods
- **[Transfer methods.md](./Transfer%20methods.md)** - Transfer object structure and transfer retrieval methods
- **[Address types.md](./Address%20types.md)** - Supported address types for different cryptocurrencies
- **[Currency methods.md](./Currency%20methods.md)** - Currency object structure and currency retrieval methods
- **[Rate methods.md](./Rate%20methods.md)** - Rate object structure and exchange rate retrieval methods
- **[Deposits.md](./Deposits.md)** - Creating and managing deposits (includes callback documentation)
- **[Payouts.md](./Payouts.md)** - Creating and managing payouts (includes travel rule, fee calculation, and callback documentation)

## Usage

These documentation files serve as reference material for the Coinsbuy API integration. You can copy-paste content from the official Coinsbuy documentation into these files for easy reference.
